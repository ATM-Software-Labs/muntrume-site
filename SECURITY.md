# Seguridad / Security

Si encuentras una vulnerabilidad en muntru.me o en su API, **no abras un issue público**.
Escribe a **info@muntru.me** (asunto: `SECURITY`) o usa *Report a vulnerability* (GitHub private vulnerability reporting) en este repositorio.

If you find a vulnerability in muntru.me or its API, please **do not open a public issue**.
Email **info@muntru.me** (subject: `SECURITY`) or use GitHub's private *Report a vulnerability*.

- Alcance: `muntru.me`, `muntrume.atrumin16.workers.dev`.
- No pruebes con cuentas de otros pilotos ni intentes acceder a archivos de setup ajenos.
- Respondemos en cuanto podamos; es un proyecto de equipo, sin programa de recompensas.
